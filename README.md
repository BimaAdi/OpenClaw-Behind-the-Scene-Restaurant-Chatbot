# How AI Agent Work
Blog and Example how AI agent work

## Requirements
- python 3.13
- uv 0.11

## Installation
- install the depedency `uv sync`
- copy .env.example to .env then fill .env
- run the example
  - `uv run python simple_chat.py`
  - `uv run python restaurant_chat_using_text.py`
  - `uv run python restaurant_chat_using_tools.py`
  - `uv run python restaurant_chat_using_mcp.py`
  - `uv run python restaurant_chat_using_mcp_streamable_http.py`
